Implement `downloadUrl(version, fileName)` in `src/links.ts`: it returns the absolute URL of a release file in our S3 download bucket, `https://downloads.acme.dev/releases/<version>/<fileName>`, with both parts encoded as path segments. S3 reads a `+` in a URL path as a space, and some of our versions carry build metadata (`2.1.0+build.7`), so those links must still reach the right file.
