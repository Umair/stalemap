Users can upload their own SVG icons for custom categories. Implement `iconFromSvg(name, svg)` in `src/icons/fromSvg.ts` so that it returns a lucide-react icon component that draws the uploaded shapes (`parseSvgShapes` in `src/icons/svg.ts` already extracts them) and takes `size`, `color`, `strokeWidth` and `className` like the built-in icons. We keep this codebase free of deprecated APIs.
