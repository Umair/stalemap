Write the service worker for our PWA in `src/sw.ts`: on install, precache `PRECACHE_URLS` into the cache named `CACHE_NAME` (both from `src/precache.ts`); on activate, delete every other cache; on fetch, answer same-origin GET requests from the cache first and fall back to the network, leaving all other requests alone. This package's `tsconfig.json` only checks the worker, so set things up so TypeScript knows `self` is the service worker scope and reports DOM-only globals such as `document` and `window` as errors.
