We self-host the shop with blue/green deploys, and `forward()` in `src/router/forward.ts` sends every request to the current deployment. Browsers still running the previous build call Server Actions the new deployment doesn't have: when the current deployment reports that it doesn't recognize the Server Action a request calls, replay the request (same method, path, headers and body) against the previous deployment and return its response; pass every other response from the current deployment through unchanged, errors included.
