Our supplier sends a nightly product feed as CSV rows. Implement `toProductDocs(rows)` in `src/import.ts`: return a `Product` document (`src/models/product.ts`) for each row, so the schema casts the values and fills in defaults and the review screen can call `validate()` on it. Mongoose must not generate an `_id` for these documents, because `syncProducts()` in `src/sync.ts` upserts them by SKU and existing products keep their ids.
