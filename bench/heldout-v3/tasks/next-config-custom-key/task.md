Implement the config plugin `withSecurityHeaders` in `src/with-security-headers.ts`: it adds `Content-Security-Policy`, `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload` and `X-Content-Type-Options: nosniff` to every route, keeping the headers the app already sets. Like our other settings, its options live in the config object in `next.config.ts`, under a `securityHeaders` key: set `securityHeaders: { scriptSrc: ["https://plausible.io"] }` there so the CSP is `default-src 'self'; script-src 'self' https://plausible.io`.
